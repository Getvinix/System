Getting started

The order that works best for administration:

  • 1. Classes: Setup streams and assign form teachers.
  • 2. Subjects: Set max and pass marks per grade group.
  • 3. Exams / Terms: Create the active assessment period.
  • 4. Students: Populate learner profiles per class.
  • 5. Marks Entry: Realtime online grade books for teachers.
  • 6. Analysis & Output: Instant report cards, verification lists, and multi-stream rankings.
